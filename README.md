# Bab Atlas Reizen — MVP-prototype

Klikbaar prototype voor een Nederlands reisbureau gespecialiseerd in Marokko:
groepsreizen, singlereizen, stedentrips en ontspanningsreizen.

## Functies
- Zoekbalk met filters (reistype, bestemming, maand, reisduur)
- Reisaanbod met sorteren op prijs en duur
- Reisdetail met dagprogramma en boekingsflow in 3 stappen
- Activiteiten en beste-reistijdtabel

## Bekijken
Open `index.html` in je browser, of zet GitHub Pages aan
(Settings → Pages → branch `main`, map `/root`).

> Prototype: prijzen, data en contactgegevens zijn voorbeelden. Er wordt niets verstuurd of geboekt.
